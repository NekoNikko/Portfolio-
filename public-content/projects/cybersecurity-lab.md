# Cybersecurity Security Lab

**Status:** COMPLETED

## Overview

An advanced cybersecurity lab using Wazuh SIEM for unified security monitoring of virtualized environments.

## What I Built

- Standardized Wazuh agents deployed across target VMs.
- Aggregation of audit logs from all monitored systems.
- Malicious process detection and system file integrity verification.
- Vulnerability monitoring across the environment.
- Custom alerting configuration to detect and log simulated brute-force and malware attacks immediately.

## Outcome

A working detection-and-response environment that demonstrates SIEM configuration, log aggregation, and alerting — the hands-on practice behind my Google Cybersecurity Professional Certificate.

## Technology

Wazuh, SIEM, threat detection, Linux, Docker, ELK Stack.
