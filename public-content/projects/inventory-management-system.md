# Inventory Management System

**Status:** COMPLETED

## Overview

A fully custom web application designed to catalog hardware assets, track status logs, and manage software license expirations across the institution.

## What I Built

- Clean dashboard interface with low-latency search.
- Hardware catalog with status history.
- Dynamic QR-code generation for physical hardware tagging.
- Automatic email notifications warning administrators of upcoming license expirations.

## Outcome

A practical tool that replaced spreadsheet-based asset tracking, directly supporting the fixed-asset auditing work performed as Lead Technical Property Officer.

## Technology

PHP, JavaScript, MySQL, Tailwind CSS, HTML5, QR Code API.
