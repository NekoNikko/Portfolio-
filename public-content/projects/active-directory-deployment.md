# Active Directory Deployment

**Status:** COMPLETED

## Overview

A comprehensive restructuring of an existing Active Directory forest to achieve enterprise role-based access control (RBAC): secure organizational units (OUs), dynamic distribution groups, automated user provisioning scripts, and rigorous audit trails.

## What I Built

- Secure organizational unit (OU) structure reflecting roles and responsibilities.
- Dynamic distribution groups for mail and resource access.
- Automated user provisioning scripts written in PowerShell.
- Rigorous audit trails for identity operations.
- Streamlined login and access permissions for students and staff across campuses.

## Outcome

Role-based access control that secured user logins across campuses and removed manual, error-prone account administration. An independent infrastructure consultant referenced this project as "a case study of excellent role-based access design."

## Technology

Active Directory, PowerShell, LDAP, Group Policy, Windows Server.
