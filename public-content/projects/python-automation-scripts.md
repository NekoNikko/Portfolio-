# Python Automation Scripts

**Status:** COMPLETED

## Overview

A collection of production automation scripts engineered in Python for government and academic audit operations.

## What I Built

- Automated parsing of school audit spreadsheets.
- Generation of unified administrative PDF reports.
- Automatic system backup monitoring.
- Notification triggers sent directly to Telegram channels upon system anomalies.

## Outcome

Eliminated over 15 hours of manual, repetitive office work per week, and replaced error-prone manual processing with deterministic scripts. This work is documented in the engineering journal article "Python-Based CSV/PDF Automation for Infrastructure Audits."

## Technology

Python, Pandas, PyPDF / ReportLab, REST APIs, cron scheduling, Git.
