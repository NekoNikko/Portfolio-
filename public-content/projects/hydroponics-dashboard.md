# Hydroponics Monitoring Dashboard

**Status:** COMPLETED

## Overview

An environmental IoT monitoring system tailored for hydroponics. Sensor telemetry (pH, electrical conductivity, water level, air temperature) is read by Python microcontrollers and streamed to a central server dashboard.

## What I Built

- Python-based sensor reading on microcontrollers.
- Real-time telemetry streaming to a central dashboard over WebSockets.
- Historical parameter charting with D3.js.
- Automatic notifications when metrics exit target optimal bands.

## Outcome

A complete IoT pipeline from physical sensors to live, charted, alerting dashboard — demonstrating full-stack integration of hardware, Python, and modern frontend tooling.

## Technology

Python, React, Tailwind CSS, IoT sensors, WebSockets, D3.js.
